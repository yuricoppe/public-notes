## Emblemas / Selos (Badges)

## Onde é usado

Badges (ou selos/etiquetas) são pequenos elementos de UI usados para destacar informações concisas e importantes, como:
- Contadores (ex: número de notificações não lidas, itens no carrinho).
- Status de um item (ex: "Novo", "Em Promoção", "Concluído", "Pendente").
- Categorias ou tags associadas a um item.
- Níveis de usuário ou conquistas (gamificação).

São geralmente posicionados próximos ao elemento ao qual se referem.

## Detalhes Adicionais / Tópicos

- **Concisão:** Devem exibir informações curtas e diretas (um número, uma palavra ou duas).
- **Contexto:** Seu significado deve ser claro dentro do contexto do elemento associado.
- **Destaque Visual:** Usam [[Glossário/Linguagem Visual/cor|cores]], formas e posicionamento para se destacar sutilmente sem sobrecarregar a interface.
- **Não Interativo:** Geralmente, badges são apenas informativos e não clicáveis (diferente de `Tags/Chips` que podem ser interativos).

## Variações

- **Badge de Contagem (Notification Badge):**
  - Descrição: Exibe um número, geralmente para indicar notificações, [[Glossário/Componentes/messaging|mensagens]] não lidas, ou quantidade de itens.
  - Estilo: [Pequeno, circular ou com cantos arredondados, cor de destaque (ex: vermelho para notificações)]
  - Conteúdo: [Apenas número, ou número com `+` se exceder um limite (ex: `99+`)]
  - Posicionamento: [Sobreposto ao canto de um ícone (ex: sino de notificação), ao lado de um item de menu]
  - Status: A definir
  - Link para o Figma: [Link para Badge de Contagem no Figma]

- **Badge de Status:**
  - Descrição: Indica o estado de um item ou processo (ex: "Ativo", "Inativo", "Sucesso", "Falha", "Em Andamento").
  - Estilo: [Pode ser retangular com cantos arredondados, usar cores semânticas (verde para sucesso, vermelho para falha, amarelo para aviso, azul para informação)]
  - Conteúdo: [Texto curto]
  - Status: A definir
  - Link para o Figma: [Link para Badge de Status no Figma]

- **Badge de Destaque/Etiqueta (Label Badge):**
  - Descrição: Para destacar uma característica especial (ex: "Novo", "Popular", "Recomendado") ou uma categoria.
  - Estilo: [Pode ter cores vibrantes ou um estilo mais sutil dependendo do destaque desejado]
  - Status: A definir
  - Link para o Figma: [Link para Badge de Destaque no Figma]

- **Badge Apenas Ponto (Dot Badge):**
  - Descrição: Um pequeno ponto colorido usado para indicar um estado (ex: online/offline) ou a presença de algo novo, sem mostrar um contador.
  - Estilo: [Pequeno círculo]
  - Cores: [Cores semânticas]
  - Status: A definir
  - Link para o Figma: [Link para Dot Badge no Figma]

## Melhores Práticas

- Mantenha o texto dos badges curto e direto ao ponto.
- Use cores de forma consistente para transmitir significado (especialmente para status).
- Não abuse de badges, pois muitos podem poluir a interface.
- Garanta contraste suficiente entre o texto do badge e seu fundo para legibilidade.
