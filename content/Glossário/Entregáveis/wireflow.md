## Wireflow

Um formato de especificação de design que combina layouts de página no estilo [[Glossário/Entregáveis/wireframe|wireframe]] com uma forma simplificada, semelhante a um fluxograma, de representar interações.

## Visão Geral

Wireflows são um entregável de UX que mescla a clareza dos [[Glossário/Entregáveis/wireframe|wireframes]] (mostrando a estrutura e os elementos de uma tela) com a lógica sequencial dos fluxogramas (mostrando como o usuário se move entre as telas ou estados da interface para completar uma tarefa).

Eles são particularmente úteis para projetar e documentar fluxos de tarefas complexos, especialmente em aplicativos móveis ou processos com muitas etapas, onde um [[Glossário/Entregáveis/site_map|sitemap]] tradicional ou fluxos de usuário puros podem não capturar suficientemente o layout da interface em cada passo.

## Componentes Chave

- **[[Glossário/Entregáveis/wireframe|Wireframes]] em Miniatura (ou Páginas-Chave):** Representações de baixa a média fidelidade das telas ou dos principais estados da interface envolvidos no fluxo.
- **Conectores/Setas:** Indicam a progressão do usuário de uma tela/estado para o próximo, mostrando a sequência das interações.
- **Anotações:** Breves descrições que explicam as ações do usuário, as condições para transições, ou outros detalhes importantes do fluxo.
- **Pontos de Decisão (Opcional):** Podem ser usados para mostrar ramificações no fluxo baseadas nas escolhas do usuário.
- **Pontos de Entrada e Saída:** Claramente definidos para o fluxo da tarefa.

## Benefícios

- **Clareza Contextual:** Mostra o layout da interface *dentro* do contexto do fluxo da tarefa.
- **Comunicação Eficaz:** Combina o "o quê" (layout) com o "como" (fluxo) em um único diagrama, facilitando a compreensão por toda a equipe.
- **Ideal para Tarefas Complexas:** Mais detalhado que um [[Glossário/Entregáveis/user_flow|User Flow]] simples e mais dinâmico que um conjunto estático de [[Glossário/Entregáveis/wireframe|wireframes]].
- **Documentação de Design:** Serve como uma especificação clara para desenvolvedores.
- **Identificação de Problemas:** Ajuda a visualizar e identificar problemas de usabilidade no fluxo e nos layouts de tela simultaneamente.
- **Foco na Tarefa:** Mantém o design centrado na conclusão de tarefas pelo usuário.

## Quando Utilizar

- **Design de Fluxos de Tarefas:** Especialmente para processos lineares ou com múltiplas etapas (ex: processo de [[Glossário/Padrões/purchase_checkout|checkout]], [[Glossário/Padrões/launch|onboarding]], configuração de perfil).
- **Aplicativos Móveis e Web Apps:** Onde o espaço da tela é limitado e o fluxo entre as telas é crítico.
- **Para comunicar designs de interação de forma detalhada para desenvolvedores.**
- **Quando User Flows sozinhos não são suficientes para transmitir o design da interface em cada etapa.**
- **Como uma evolução dos User Flows, adicionando detalhes de layout.**

## Wireflow vs. [[Glossário/Entregáveis/user_flow|User Flow]] vs. [[Glossário/Entregáveis/wireframe|Wireframe]]

- **[[Glossário/Entregáveis/user_flow|User Flow]]:** Abstrato, foca na sequência lógica de ações e decisões, sem necessariamente mostrar o layout da tela.
- **[[Glossário/Entregáveis/wireframe|Wireframe]]:** Estático, mostra o layout e os elementos de uma única tela ou estado, sem detalhar o fluxo para outras telas.
- **Wireflow:** Combina os dois, mostrando múltiplos [[Glossário/Entregáveis/wireframe|wireframes]] em miniatura conectados para ilustrar um fluxo de tarefa completo.

## Considerações

- **Nível de Fidelidade dos [[Glossário/Entregáveis/wireframe|Wireframes]]:** Geralmente de baixa a média fidelidade para manter o foco no fluxo e na estrutura, não nos detalhes visuais.
- **Complexidade do Diagrama:** Para fluxos muito longos ou ramificados, pode se tornar complexo. Dividir em sub-fluxos pode ser útil.
- **Ferramentas:** Pode ser criado com ferramentas de design (Figma, Sketch, Adobe XD), ferramentas de diagramação ou até mesmo manualmente.
- **Manutenção:** Como qualquer documentação de design, precisa ser mantido atualizado conforme o design evolui.
