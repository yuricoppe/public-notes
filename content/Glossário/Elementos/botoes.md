## Botões (Buttons)

## Onde é usado

Botões são elementos interativos que permitem aos usuários realizar ações, como enviar [[Glossário/Padrões/form_structure|formulários]], confirmar escolhas, navegar para funcionalidades específicas, ou iniciar processos.

## Lista de subcomponentes

- Texto do Botão
- [[Glossário/Linguagem Visual/iconografia|Ícone]] (opcional, pode ser à esquerda ou à direita do texto)

## Variações

![Hierarquia de botões: primário preenchido, secundário com contorno e terciário só texto; abaixo, os cinco estados do botão primário — padrão, hover, foco com anel, pressionado e desabilitado](attachments/glossario-hierarquia-botoes.svg)

- **Botão Primário:**
  - Descrição: Para a ação principal e mais importante em uma tela ou contexto.
  - Estilo: [Ex: Fundo sólido com cor primária, texto contrastante]
  - Status: A definir
  - Link para o Figma: [Link para Botão Primário no Figma]

- **Botão Secundário:**
  - Descrição: Para ações secundárias que complementam a ação primária.
  - Estilo: [Ex: Contorno com cor primária, texto na cor primária, fundo transparente ou claro]
  - Status: A definir
  - Link para o Figma: [Link para Botão Secundário no Figma]

- **Botão Terciário/Texto:**
  - Descrição: Para ações menos proeminentes, muitas vezes usado para opções discretas ou links que precisam de uma área de clique maior.
  - Estilo: [Ex: Apenas texto, sem borda ou fundo proeminente, cor do link]
  - Status: A definir
  - Link para o Figma: [Link para Botão Terciário no Figma]

- **Botão com Ícone:**
  - Descrição: Botão que inclui um ícone para reforçar visualmente a ação.
  - Posição do Ícone: [Esquerda/Direita]
  - Variações: Pode ser aplicado a botões primários, secundários ou terciários.
  - Status: A definir
  - Link para o Figma: [Link para Botões com Ícone no Figma]

- **Botão de Grupo (Button Groups):**
  - Descrição: Agrupamento de dois ou mais botões relacionados horizontalmente.
  - Estilo: [Ex: Botões conectados, com bordas compartilhadas]
  - Status: A definir
  - Link para o Figma: [Link para Grupos de Botões no Figma]

- **Botões de [[Glossário/Componentes/menu|Menu]] (Menu buttons):**
  - Descrição: Botão que, ao ser clicado, revela um menu [[Glossário/Elementos/form_controls|dropdown]] com mais opções.
  - Ícone Indicador: [Ex: Seta para baixo]
  - Status: A definir
  - Link para o Figma: [Link para Botões de Menu no Figma]

- **Botões Divididos (Split buttons):**
  - Descrição: Combinação de um botão de ação principal com um botão adjacente que revela um menu dropdown com ações secundárias relacionadas.
  - Status: A definir
  - Link para o Figma: [Link para Botões Divididos no Figma]

- **FAB (Floating Action Button):**
  - Descrição: Um botão circular, geralmente com um ícone, que flutua acima da interface para promover uma ação principal ou comum.
  - Posição: [Ex: Canto inferior direito]
  - Status: A definir
  - Link para o Figma: [Link para FAB no Figma]
