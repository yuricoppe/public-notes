## Botões (Buttons)

## Onde é usado

Botões são elementos interativos que permitem aos usuários realizar ações, como enviar [[Glossário/Padrões/form_structure|formulários]], confirmar escolhas, navegar para funcionalidades específicas, ou iniciar processos.

## [[Glossário/Elementos/listas|Lista]] de subcomponentes

- Texto do Botão
- [[Glossário/Linguagem Visual/iconografia|Ícone]] (opcional, pode ser à esquerda ou à direita do texto)

## Variações

- **Botão Primário:**
  - Descrição: Para a ação principal e mais importante em uma tela ou contexto.
  - Estilo: [Ex: Fundo sólido com [[Glossário/Linguagem Visual/cor|cor]] primária, texto contrastante]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botão Primário no Figma]

- **Botão Secundário:**
  - Descrição: Para ações secundárias que complementam a ação primária.
  - Estilo: [Ex: Contorno com [[Glossário/Linguagem Visual/cor|cor]] primária, texto na [[Glossário/Linguagem Visual/cor|cor]] primária, fundo transparente ou claro]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botão Secundário no Figma]

- **Botão Terciário/Texto:**
  - Descrição: Para ações menos proeminentes, muitas vezes usado para opções discretas ou [[Glossário/Elementos/links|links]] que precisam de uma área de clique maior.
  - Estilo: [Ex: Apenas texto, sem borda ou fundo proeminente, [[Glossário/Linguagem Visual/cor|cor]] do [[Glossário/Elementos/links|link]]]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botão Terciário no Figma]

- **Botão com [[Glossário/Linguagem Visual/iconografia|Ícone]]:**
  - Descrição: Botão que inclui um [[Glossário/Linguagem Visual/iconografia|ícone]] para reforçar visualmente a ação.
  - Posição do [[Glossário/Linguagem Visual/iconografia|Ícone]]: [Esquerda/Direita]
  - Variações: Pode ser aplicado a botões primários, secundários ou terciários.
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botões com [[Glossário/Linguagem Visual/iconografia|Ícone]] no Figma]

- **Botão de Grupo (Button Groups):**
  - Descrição: Agrupamento de dois ou mais botões relacionados horizontalmente.
  - Estilo: [Ex: Botões conectados, com bordas compartilhadas]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Grupos de Botões no Figma]

- **Botões de [[Glossário/Componentes/menu|Menu]] ([[Glossário/Componentes/menu|Menu]] buttons):**
  - Descrição: Botão que, ao ser clicado, revela um [[Glossário/Componentes/menu|menu]] [[Glossário/Elementos/form_controls|dropdown]] com mais opções.
  - [[Glossário/Linguagem Visual/iconografia|Ícone]] Indicador: [Ex: Seta para baixo]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botões de [[Glossário/Componentes/menu|Menu]] no Figma]

- **Botões Divididos (Split buttons):**
  - Descrição: Combinação de um botão de ação principal com um botão adjacente que revela um [[Glossário/Componentes/menu|menu]] [[Glossário/Elementos/form_controls|dropdown]] com ações secundárias relacionadas.
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para Botões Divididos no Figma]

- **FAB (Floating Action Button):**
  - Descrição: Um botão circular, geralmente com um [[Glossário/Linguagem Visual/iconografia|ícone]], que flutua acima da interface para promover uma ação principal ou comum.
  - Posição: [Ex: Canto inferior direito]
  - Status: A definir
  - [[Glossário/Elementos/links|Link]] para o Figma: [[[Glossário/Elementos/links|Link]] para FAB no Figma]
