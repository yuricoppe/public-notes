# Código (Code)

## Onde é usado

Utilizado para exibir trechos de código inline (dentro de um [[Elementos/paragrafo|parágrafo]]) ou em blocos de código maiores (para exemplos mais extensos), comum em documentações técnicas e tutoriais.

## Detalhes Adicionais / Tópicos

- **Código Inline:** Para nomes de variáveis, funções, tags curtas, etc.
- **Bloco de Código:** Para exemplos de múltiplas linhas, com destaque de sintaxe (syntax highlighting) se possível.
- [[Linguagem Visual/tipografia|Tipografia]] monoespaçada para melhor legibilidade do código.
- Opção de copiar código para a área de transferência.
