# Citação em Bloco (Block Quote)

## Onde é usado

Utilizado para destacar citações diretas ou trechos de texto que são retirados de outra fonte. Geralmente é recuado e/ou estilizado de forma diferente do texto ao redor.

## Detalhes Adicionais / Tópicos

- Pode incluir uma borda lateral, fundo diferente ou [[Linguagem Visual/tipografia|tipografia]] específica.
- Pode ter um elemento para atribuir a fonte da citação.

## Variações

- **Block Quote Padrão:**
  - Descrição: Estilo base para citações em bloco.
  - Estilo Visual: [Ex: Recuo, borda esquerda, [[Linguagem Visual/cor|cor]] de fundo sutil]
  - [[Linguagem Visual/tipografia|Tipografia]]: [Ex: Itálico, tamanho ligeiramente menor ou igual ao [[Elementos/paragrafo|parágrafo]]]
  - Status: A definir
  - [[Elementos/links|Link]] para o Figma: [[[Elementos/links|Link]] para Block Quote Padrão no Figma]

- **Block Quote com Atribuição:**
  - Descrição: Inclui um espaço para citar o autor ou a fonte.
  - Elemento de Atribuição: [Ex: Texto menor abaixo da citação]
  - Status: A definir
  - [[Elementos/links|Link]] para o Figma: [[[Elementos/links|Link]] para Block Quote com Atribuição no Figma]
