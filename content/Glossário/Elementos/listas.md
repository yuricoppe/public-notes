# Listas (Lists)

## Onde é usado

Listas são usadas para agrupar itens relacionados de forma ordenada (numerada) ou não ordenada (com marcadores). São essenciais para apresentar informações de maneira clara e escaneável.

## Detalhes Adicionais / Tópicos

- **Listas Não Ordenadas (`<ul>`):** Usam marcadores (bullets).
- **Listas Ordenadas (`<ol>`):** Usam números ou letras.
- **Listas de Definição (`<dl>`):** Usadas para pares de termo/descrição (menos comum, mas útil para glossários, etc.).
- Aninhamento de listas.
- Estilo dos marcadores/números e [[Linguagem Visual/espacamento|espaçamento]].

## Variações

- **Lista Não Ordenada Padrão:**
  - Descrição: Para itens onde a ordem não importa.
  - Marcador: [Ex: Círculo cheio, círculo vazio, quadrado]
  - [[Linguagem Visual/espacamento|Espaçamento]] entre itens: [Ex: 8px]
  - Recuo: [Ex: 20px]
  - Status: A definir
  - [[Elementos/links|Link]] para o Figma: [[[Elementos/links|Link]] para Lista Não Ordenada no Figma]

- **Lista Ordenada Padrão:**
  - Descrição: Para itens onde a sequência é importante (passos, rankings).
  - Numeração: [Ex: 1, 2, 3...; a, b, c...; I, II, III...]
  - [[Linguagem Visual/espacamento|Espaçamento]] entre itens: [Ex: 8px]
  - Recuo: [Ex: 20px]
  - Status: A definir
  - [[Elementos/links|Link]] para o Figma: [[[Elementos/links|Link]] para Lista Ordenada no Figma]

- **Lista Aninhada:**
  - Descrição: Listas dentro de outras listas, com marcadores/numeração e recuo distintos para indicar hierarquia.
  - Status: A definir
