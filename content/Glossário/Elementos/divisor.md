## Divisor / Régua (Divider / Rule)

## Onde é usado

Divisores ou réguas horizontais (e às vezes verticais) são usados para separar visualmente seções de conteúdo ou grupos de elementos, ajudando a organizar a informação e melhorar a clareza do layout.

## Detalhes Adicionais / Tópicos

- Usados para criar separação e agrupamento visual.
- Podem ser de largura total ou parcial.
- Estilo: [[Glossário/Linguagem Visual/cor|Cor]], espessura, tracejado (opcional).

## Variações

- **Divisor Padrão (Horizontal):**
  - Descrição: Linha horizontal para separar conteúdo.
  - Espessura: [Ex: 1px]
  - Cor: [Ex: Cor neutra sutil, como cinza claro]
  - Margem: [Ex: Vertical, para dar respiro ao redor do divisor]
  - Status: A definir
  - Link para o Figma: [Link para Divisor Padrão no Figma]

- **Divisor com Texto/[[Glossário/Linguagem Visual/iconografia|Ícone]] (Ornamental):**
  - Descrição: Divisor que incorpora texto (ex: "Ou") ou um ícone no centro, para separações mais estilizadas.
  - Status: A definir
  - Link para o Figma: [Link para Divisor Ornamental no Figma]

- **Divisor Vertical:**
  - Descrição: Linha vertical para separar elementos lado a lado (menos comum para conteúdo principal, mais para componentes específicos).
  - Status: A definir
  - Link para o Figma: [Link para Divisor Vertical no Figma]
